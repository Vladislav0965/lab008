# lab008
Словарь — оптимальный выбор, когда данные имеют именованные поля, требуется быстрый доступ по ключу, возможна динамическая смена структуры и часто приходится взаимодействовать с внешними источниками данных в формате «ключ‑значение». 
Выбор структуры зависит от задачи: для именованных данных берут словарь, чтобы обращаться по ключам и быстро получать значения, для уникальных элементов — множество, гарантирующее отсутствие дублей, для упорядоченных последовательностей — список; метод .get() у словаря безопасно возвращает значение по ключу либо заданное по умолчанию при его отсутствии, избегая ошибок KeyError; множество сортируют через sorted() перед выводом, потому что оно неупорядочено и без сортировки порядок элементов будет произвольным, а sorted() возвращает предсказуемый список.
